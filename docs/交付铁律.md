# 交付铁律：两条从真实缺陷长出来的规矩

> 这不是流程口号。**每一条都对应一次"本地全绿、交付即翻车"的真实事故**，
> 且都记着**症状**，以便下次一眼认出。

---

## 铁律一：输出编码不许依赖环境变量

**症状**：`CP-D` 现场验收时，`tests/e2e/test_demo_launcher.py` 的
`assert '已启动' in log` 失败，中文全是 `\ufffd`。
根因不是代码，是**干净环境下 `cp936` / stdout `gbk`** ⇒ Python 把中文按 GBK 写出，测试按 UTF-8 读。

**修法**：`app/console.py::force_utf8_stdio()` ——
**输出被重定向或进管道时强制 UTF-8**（写给机器看的必须与 locale 无关），
**接真控制台时沿用控制台编码**（中文才显示得对）。`sim/` 侧同理有 `sim/core/console.py`
（两份各自独立，因为 `sim/**` 不得 `import app`）。

**规矩**：
1. `run.py` / `scripts/launch.py` / `sim` 的输出一律经自己的 `console.py` 定编码；
2. **测试捕获子进程输出一律显式 `encoding="utf-8", errors="replace"`**；
3. **验收基线 = 清掉 `PYTHONUTF8` / `PYTHONIOENCODING` 后仍然全绿**。

> 「靠环境变量才通过」不算通过 —— **那意味着我这台绿、你那台满屏乱码**。

## 铁律二：交付前跑一次「新克隆验证」

**症状**：`.gitignore` 里一行**未锚定**的 `env/` 会匹配**任意层级**名为 `env` 的目录，
于是 `sim/env/`（仿真的环境层）被静默忽略。
`git ls-files sim/env` **为空** —— `T-SIM-02` 那次提交只进了 `params.json`，
**整个环境层根本没入库**。而工作区里文件都在、测试全绿，**本地怎么跑都发现不了**。

**修法**：按成因修 —— 把虚拟环境规则**锚定到仓库根**（`/env/`），**而不是给 `sim/env/` 开个洞**。

**规矩**：每次交付前依次做——
1. `git ls-files` 自检：关键目录是否都真的被跟踪；
2. **真 `git clone` 到另一个盘**，确认文件数一致、关键目录在；
3. **在克隆里跑全量测试**。

## 铁律二第二次兑现：e2e 用例在快盘上红、在慢盘上绿（2026-10-03）

**症状**：新克隆验证里，`tests/e2e/test_demo_requirements.py::test_offline_rehearsal_uses_multi_item_and_accumulates`
在 **C: 盘克隆里稳定失败（4/4）**，而 **D: 盘同一份内容的源仓库稳定通过（3/3）**。

**判别实验**（逐步排除，不是猜）：
- 换行符？把克隆里 189 个文件全转成 CRLF —— **仍失败** ⇒ 排除；
- 残留进程 / 端口占用？清掉所有 `run.py` 进程后全新克隆 —— **仍失败** ⇒ 排除；
- 测试顺序依赖？跑整个文件、只跑两个 offline 用例 —— **都失败** ⇒ 排除；
- 页面乱码？浏览器 dump 两边 DOM —— **完全一致**，乱码是本机控制台的渲染 ⇒ 排除；
- 位置因素？把**同一份 HEAD 内容**解到 **D: 盘另一个路径** —— **通过**；
  同一时刻 C: 盘克隆 —— **失败** ⇒ **锁定位置**。

**根因（两盘对拍实测）**：点击前 `#defaultStall` 的 DOM 状态在两个盘上**逐项相同**
（`w=135.69 h=46.8 / display=block / visibility=visible / tiles=0 / readyState=complete`），
但 **C: 盘超时 5s、D: 盘成功**。
差别不在"元素不可见"，而在 **Playwright 的 stability 检查** ——
它要求元素几何框在连续两帧间不变。
快盘（实测 C: 的 fsync **2ms** vs D: 的 **37ms**）上应用**更快**地恢复"已选摊位"并重排布局，
检查就一直过不去；慢盘上恰好落进静止窗口。

**即：用例在 `reload()` 后立刻点击，与应用初始化赛跑 ——
它在替代码撒谎：快机器上红、慢机器上绿。而评委的机器多半是 SSD。**

**修法**：`reload()` 之后应用本就会从 localStorage 恢复已选摊位并收起选择器
（实测约 250ms 后 `.tile` 就绪、25 个）⇒ **那次点击既多余又危险**。
改为等待**确定性就绪态** `.tile`；若摊位**没有**被恢复，`.tile` 永不出现、
用例**响亮失败**，不再靠一次时机碰运气的点击蒙混。

**验证**：C: 盘 **2/2 通过**（原先 0/4，耗时 27s → 7.9s），D: 盘仍通过。

## 由此追加的纪律

**测试不等于结论。** 任何一条"全绿"的记录，都要问一句：
**它在什么机器上绿？**

- 一个只在慢盘上绿的 e2e 用例，和一个失败的用例**同样不可交付**；
- **交付验证必须在"和评委不同的环境"里做一次** —— 换盘、换路径、换克隆，都是环境变量。

> 两次铁律的共同点：**它们都不是"多写一条测试"，而是"换一个环境再验一次"。**
